# Tripleten web_project_around_full

Client
App web con registro de usuarios, inicio de sesión, opciones para editar el perfil del usuario, agregar contenido a tu perfil y función de dar like a una publicación
Rutas protegidas por autenticación.
Se utilizaron tecnologías como HTML, CSS, TypeScript, React y VITE

Server
Funciones GET para users y cards.
Funciones POST, PUT y PATCH para actualizar perfil, agregar cartas, eliminarlas y dar like a las cartas
Funciones POST para registarse e iniciar sesión con autenticación

Se usaron tecnología como express para la creación de rutas, controladores y middleware.
Se utilizó mongoose para la conexión a MongoBD

También se utilizaron tecnologías como ESlint, TypeScript, prettier y editorConfig como devDependences para una mejor calidad de código

Rutas disponibles:
/users
/users/user_id
/cards
/signin
/signup
/users/me
